# SpecNet-v1.0-Prior-attention-CNN-for-Raman-based-PVC-additive-identification
SpecNet identifies 14 additive classes &amp; 2 PVC types from micro-Raman spectra using spectral chunking, cross-attention, and BCE+L1 loss. Achieves 98.67% F1, 2.5 wt% TCPP detection limit. Includes zero‑shot transfer to other polymers and aging adaptation.
